# CampusHaat Frontend

A verified-only marketplace web application built for university students to buy, sell, and trade items safely within their campus community.

## Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Custom Animations
- **Icons**: Lucide React
- **State & Data**: Zustand + TanStack Query

## Key Features
- **Cinematic Hero**: Full-screen video loop with liquid glass UI & student verification entry
- **Campus Marketplace**: Category showcases, search, and local item browsing
- **Auth & Profiles**: Student email verification (.edu / .ac.in), user profiles, and listing creation
- **Interactive Elements**: Glassmorphism cards, specular buttons, and responsive UI

## Getting Started
```bash
npm install
npm run dev
```
